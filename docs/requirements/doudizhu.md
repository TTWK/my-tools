# 斗地主计分器需求文档

## 概述

斗地主计分器支持经典三人斗地主规则，包含叫分/抢地主、炸弹翻倍、春天/反春天等规则。

## 游戏规则要点

### 基本规则
- **人数**: 3人
- **牌数**: 54张（含大小王）
- **角色**: 1地主 vs 2农民
- **出牌顺序**: 地主先出

### 叫分/抢地主规则

#### 经典叫分模式
| 分值 | 说明 |
|------|------|
| 1分 | 保守叫分，牌力一般 |
| 2分 | 较好牌型 |
| 3分 | 牌力很强，强势叫分 |

- 叫分最高者成为地主
- 若3人都叫1分，则重新发牌
- 若有人叫3分，直接成为地主

#### 抢地主模式
- 初始叫分后，其他玩家可选择"抢地主"
- 每抢一次，倍数翻倍
- 最后抢到地主者成为地主

### 牌型与大小

#### 单牌大小
大王 > 小王 > 2 > A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3

#### 基本牌型
| 牌型 | 说明 | 示例 |
|------|------|------|
| 单牌 | 任意一张牌 | 3 |
| 对子 | 两张相同点数 | 33 |
| 三张 | 三张相同点数 | 333 |
| 三带一 | 三张+单牌 | 333+4 |
| 三带二 | 三张+对子 | 333+44 |
| 顺子 | 5张及以上连续单牌 | 34567 |
| 连对 | 3对及以上连续对子 | 334455 |
| 飞机 | 两组及以上连续三张 | 333444 |
| 飞机带翅膀 | 飞机+同数量单牌/对子 | 333444+57 |
| 四带二 | 四张+两张单牌/两对 | 3333+45 |

#### 特殊牌型
| 牌型 | 说明 | 大小 |
|------|------|------|
| 炸弹 | 四张相同点数 | 除火箭外最大，点数大者大 |
| 火箭（王炸） | 大王+小王 | 最大牌型 |

### 计分规则

#### 基础公式
```
最终得分 = 基础分 × 倍数
```

#### 倍数计算
| 情况 | 倍数 |
|------|------|
| 初始倍数 | 1倍（叫分）或叫分值 |
| 抢地主 | 每抢一次 ×2 |
| 炸弹 | 每出一个炸弹 ×2 |
| 火箭 | 出火箭 ×2 |
| 春天 | 地主获胜且农民未出牌 ×2 |
| 反春天 | 农民获胜且地主只出一手牌 ×2 |

**倍数封顶**: 通常64倍或128倍（可自行设置）

#### 输赢计算
- **地主胜利**: 每位农民支付 `基础分 × 倍数`
- **地主失败**: 地主支付每位农民 `基础分 × 倍数`

#### 示例
场景：叫分3分，抢地主2次，出一个炸弹，地主获胜
- 倍数 = 3 × 2 × 2 × 2 = 24倍
- 若基础分为1分，每位农民支付24分
- 地主获得 24 × 2 = 48分

## 功能需求

### 基础功能
1. **创建对局**
   - 选择叫分模式（经典叫分/抢地主）
   - 设置基础分（1分/2分/5分/10分）
   - 设置倍数封顶（32倍/64倍/128倍/无上限）
   - 选择是否启用春天/反春天翻倍

2. **角色分配**
   - 记录叫分过程
   - 自动计算抢地主倍数
   - 确定地主和农民
   - 显示角色标识

3. **记牌器**（可选）
   - 记录已出的炸弹数量
   - 记录剩余牌数
   - 提示春天可能性

4. **计分功能**
   - 每局结束自动计算分数
   - 支持手动输入倍数调整
   - 显示倍数明细
   - 支持悔牌/撤销

### 高级功能
1. **战绩统计**
   - 地主胜率
   - 平均叫分
   - 炸弹出现频率
   - 春天/反春天次数

2. **牌局回放**
   - 记录每局过程
   - 支持查看历史牌局

## 数据结构

### 斗地主配置
```typescript
interface DoudizhuConfig {
  // 基础设置
  baseScore: number;        // 基础分
  maxMultiplier: number;    // 倍数封顶

  // 叫分模式: 'call' | 'grab'
  // 'call': 经典叫分模式（1/2/3分）
  // 'grab': 抢地主模式
  mode: 'call' | 'grab';

  // 倍数规则
  bombMultiplier: number;   // 炸弹倍数
  rocketMultiplier: number; // 火箭倍数
  springMultiplier: number; // 春天倍数
  antiSpringMultiplier: number; // 反春天倍数

  // 特殊规则
  enableSpring: boolean;    // 启用春天
  enableCardTracker: boolean; // 启用记牌器
}
```

### 对局记录
```typescript
interface DoudizhuRound {
  id: string;
  gameId: string;
  roundNumber: number;
  createdAt: number;

  // 角色
  landlordId: string;  // 地主ID
  farmerIds: string[];   // 农民IDs

  // 叫分过程
  bids: Array<{
    playerId: string;
    score: number;  // 叫分（0-3，0表示不叫）
    isGrab: boolean; // 是否抢地主
  }>;

  // 倍数计算
  baseScore: number;     // 基础分（最高叫分）
  grabMultiplier: number; // 抢地主倍数
  bombCount: number;     // 炸弹数量
  hasRocket: boolean;    // 是否有火箭
  isSpring: boolean;     // 是否春天
  isAntiSpring: boolean; // 是否反春天

  // 最终倍数
  totalMultiplier: number;

  // 分数结果
  playerResults: Record<string, number>;

  // 备注
  note?: string;
}
```
