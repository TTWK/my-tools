# 用户反馈收集需求文档

## 目标

提供简单、低打扰的反馈入口，沉淀问题描述与上下文信息，便于后续优化迭代。

## 功能需求

1. 反馈入口
   - 工具首页提供“反馈与建议”入口
   - 计分器页面提供快捷入口（可选）
2. 反馈内容
   - 问题描述（必填）
   - 联系方式（选填）
   - 当前工具与页面路径（自动采集）
   - 设备与版本信息（自动采集，不含敏感信息）
3. 存储与上报
   - 默认本地保存，离线可提交
   - 若启用云同步（CloudBase），可一键上报到云端集合

## 验收标准

1. 未联网时提交反馈，仍能本地保存并在列表中可查看
2. 已联网且启用云同步时，提交反馈会尝试上报，失败不影响本地保存
3. 反馈数据不包含敏感信息（token、隐私内容等）
