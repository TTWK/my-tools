# 福州麻将计分器需求文档

## 概述

福州麻将计分器是专为福州地区麻将规则设计的计分模块，支持福州麻将特有的番数计算规则。

## 福州麻将规则要点

### 基本规则
- **人数**: 4人
- **牌数**: 136张（万、条、筒各1-9，东南西北中发白各4张）+ 8张花牌
- **花牌**: 春、夏、秋、冬、梅、兰、竹、菊
- **金牌**: 翻牌后确定的一张牌为金牌（万能牌）

### 胡牌条件
- 必须有花牌或杠牌才能胡牌
- 至少有一番才能胡牌
- 基本牌型：四面子+一对将

### 番数计算（福州规则）

#### 基础番数
| 牌型 | 番数 | 说明 |
|------|------|------|
| 平胡 | 1番 | 基本胡牌 |
| 花牌 | 每朵0.5番 | 春夏秋冬梅兰竹菊 |
| 金牌 | 1番 | 自摸金牌胡 |
| 自摸 | 1番 | 自摸胡牌 |

#### 杠牌番数
| 杠型 | 番数 | 说明 |
|------|------|------|
| 明杠 | 1番 | 碰后杠或直杠 |
| 暗杠 | 2番 | 自己摸到四张 |
| 加杠 | 1番 | 碰后补杠 |

#### 特殊牌型番数
| 牌型 | 番数 | 说明 |
|------|------|------|
| 断幺九 | 1番 | 没有幺九和字牌 |
| 混一色 | 2番 | 一种花色+字牌 |
| 清一色 | 4番 | 同一种花色 |
| 碰碰胡 | 2番 | 全是对子 |
| 七对子 | 2番 | 七个对子 |
| 十三幺 | 8番 | 全幺九字牌各一张+其中一对 |
| 全求人 | 2番 | 全部碰或吃，单吊将 |
| 杠上开花 | 2番 | 杠牌后摸牌胡 |
| 抢杠胡 | 1番 | 抢别人加杠胡 |
| 海底捞月 | 1番 | 最后一张牌自摸 |
| 妙手回春 | 1番 | 最后一张牌点炮 |

#### 庄家连庄
| 情况 | 番数 | 说明 |
|------|------|------|
| 庄家 | 0.5番 | 基础庄家加成 |
| 连庄 | 每把+0.5番 | 连续坐庄加成 |
| 最高 | 2番 | 连庄最高封顶 |

### 封顶规则
- 最高封顶：8番
- 连庄封顶：2番（最高4连庄）
- 花牌封顶：最多计算8朵花（4番）

## 功能需求

### 基础功能
1. **创建对局**
   - 选择福州麻将规则
   - 设置底分（一番对应的基础分数）
   - 设置封顶番数（默认8番）
   - 设置庄家连庄规则

2. **番数计算器**
   - 选择胡牌类型（自摸/点炮）
   - 选择牌型组合（可多选）
   - 输入杠牌情况（明杠/暗杠数量）
   - 输入花牌数量
   - 选择庄家/连庄情况
   - 自动计算总番数和分数

3. **记分功能**
   - 记录每局番数和输赢分数
   - 支持悔牌/撤销
   - 显示实时分数排名
   - 显示连庄情况

### 高级功能
1. **牌型识别**
   - 拍照识别牌型（可选）
   - 手动输入牌型计算番数

2. **战绩统计**
   - 胡牌率统计
   - 平均番数
   - 最常胡的牌型
   - 输赢走势

3. **规则自定义**
   - 调整番数表
   - 开启/关闭某些规则
   - 自定义封顶规则

## 数据结构

### 福州麻将配置
```typescript
interface FuzhouMahjongConfig {
  // 基础设置
  baseScore: number;        // 底分（一番对应的分数）
  maxCap: number;           // 最高封顶番数
  maxDealerStreak: number;  // 最高连庄次数

  // 花牌设置
  flowerBonus: number;      // 每朵花的番数
  maxFlowerBonus: number;   // 花牌最高加成

  // 金牌设置
  goldCardBonus: number;    // 金牌番数

  // 杠牌设置
  exposedKongBonus: number;   // 明杠番数
  concealedKongBonus: number;  // 暗杠番数

  // 自摸加成
  selfDrawBonus: number;    // 自摸番数
  kongDrawBonus: number;    // 杠上开花番数

  // 庄家设置
  dealerBonus: number;      // 庄家基础加成
  dealerStreakBonus: number;// 每连庄加成
}
```

### 番数计算记录
```typescript
interface MahjongFanRecord {
  id: string;
  roundId: string;
  createdAt: number;

  // 胡牌信息
  winnerId: string;
  dealerId: string;
  isSelfDraw: boolean;

  // 番数明细
  fans: Array<{
    type: FanType;
    name: string;
    value: number;

  actualFan: number;     // 实际计算番数（封顶后）

  playerResults: Record<string, number>;
}
```

## 验收标准

1. ✅ 能正确创建福州麻将对局并设置规则参数
2. ✅ 番数计算器能正确识别所有福州麻将牌型
3. ✅ 番数计算符合福州本地规则（包括连庄、封顶等）
4. ✅ 能正确记录每局胡牌的番数明细和分数
5. ✅ 支持撤销/重做操作
6. ✅ 实时显示玩家排名和分数统计
