# 棋牌桌游计分器（Scorekeeper）需求文档

## 目标与范围

计分器作为工具聚合平台的首个核心功能，提供“离线可用”的记分体验，并为后续更多工具的接入验证整体架构可扩展性。

## 用户故事

1. 作为玩家，我可以创建一场对局，选择游戏类型并添加玩家。
2. 作为记分人，我可以按“局/回合”记录每位玩家的得分增减，并可撤销/重做。
3. 作为玩家，我可以查看对局历史记录与每局明细，必要时导出分享。

## 术语

- 对局（Game）：一次完整的记分过程
- 回合（Round）：一次记分操作，包含对多个玩家的分数变更
- 事件（Event）：回合的持久化表达（事件溯源）

## 功能需求

### 1. 多游戏类型

- 支持创建对局时选择游戏类型：\n - 通用加减分（Generic）\n - 麻将（Mahjong，先以“预设模板+可配置参数”落地）\n - 扑克（Poker，先以“预设模板+可配置参数”落地）
- 不同游戏类型可携带配置（例如底分、结算规则提示），并可在后续扩展为规则插件。

### 2. 玩家管理

- 创建对局时添加玩家（至少 2 人）\n- 对局内支持：\n - 添加玩家\n - 修改玩家名称\n - 删除玩家（仅当该玩家未参与任何回合，或在 UI 上明确提示风险）

### 3. 分数记录

- 以“回合”为单位记录分数变更：每回合可对多个玩家同时加/减分
- 自动计算并展示累计总分
- 支持回合备注
- 支持撤销/重做（Undo/Redo）

### 4. 历史记录查看

- 查看对局的回合列表（时间、备注、各玩家得分变更）
- 可切换查看“已撤销回合”（只读展示）

## 非功能性要求

- 离线可用：无网可完成创建对局、记分与历史查看（持久化与云同步在后续任务完成）
- 可测试：业务规则必须可单元测试覆盖
- 可维护：复杂规则下沉到 domain 层，UI 保持薄

## 验收标准（可直接映射到测试用例）

1. 创建对局后，初始总分均为 0，玩家顺序与名称正确展示。
2. 新增一回合，输入每位玩家分数变更后，总分随之正确变化。
3. 撤销最近一回合后，总分恢复到撤销前状态，且该回合在“已撤销回合”中可见。
4. 重做一回合后，总分再次应用该回合变更。
5. 添加/编辑玩家名称后，历史回合展示仍能正确关联到该玩家。
